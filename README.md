# funding-radar

跨交易所资金费率对比雷达。用于**发现**同一标的在不同永续合约交易所之间的
资金费率差，为中性套利（在费率最负的所做多 + 在费率最正的所做空）提供数据依据。

> 本项目只做数据采集与展示，不下单、不接触任何交易凭据。
> 页面内容仅供研究，不构成投资建议。

## 为什么需要它

单边做多收负资金费**不是套利**，那是带息的单边多头，价格风险没有对冲。
中性做法是同一标的两条腿：

```
在 A 所做多（该所费率最低/最负 -> 你收钱或少付钱）
在 B 所做空（该所费率最高/最正 -> 你收钱）
净收 = rate(B) - rate(A)
```

本项目算的 `net_apr` 就是这个差值。

## 三个容易算错的地方

1. **结算周期不同**。各所 1h / 4h / 8h 不等，新上或高波动合约常被临时改成 4h。
   同样显示 0.05%，周期不同实际差 8 倍。本项目一律先折算成年化再比较。
2. **两条腿都占保证金**。资金被摊成两半，对总投入的实际年化约为 `net_apr / 2`，
   再扣两边开平仓手续费。
3. **基差风险**。股票类 / pre-IPO 合约没有可交割现货，两所价格没有强制收敛的
   力量。你以为对冲掉了方向风险，实际是换成了基差风险。表里的「基差」列要看
   它在历史上的波动幅度，而不是此刻的数值。

## 快速开始

```bash
cp .env.example .env
docker compose up -d --build

# 找标的在各所的真实符号（不要猜，跨所命名差异很大）
docker compose run --rm radar python -m app.discover CXMT
docker compose run --rm radar python -m app.discover UNITREE

# 把符号填进 config/universe.json，自动生效，无需重启
```

看板走 SSH 隧道访问，服务只绑 `127.0.0.1`，不开公网端口：

```bash
# 在你自己电脑上
ssh -i <key>.pem -L 8080:127.0.0.1:8080 ubuntu@<服务器IP>
# 然后浏览器打开 http://127.0.0.1:8080
```

## 接口

| 路径 | 说明 |
|---|---|
| `/` | 看板页面，60 秒自动刷新 |
| `/api/latest` | 最近一轮的 JSON |
| `/healthz` | 存活探针 |

## 目录

```
app/venues.py    各所适配器 + 年化折算（核心口径在这里）
app/core.py      读 universe -> 拉快照 -> 配对
app/store.py     SQLite 存储与历史查询
app/web.py       服务端渲染看板
app/discover.py  按关键词跨所搜符号
config/universe.json  标的映射表（唯一需要你手工维护的东西）
```

## 依赖

只用 Python 标准库，没有 pip 依赖。镜像小、构建快、无供应链风险。
